## 1. 业务背景与现状分析

### 1.1 当前系统HR功能现状

| 功能模块 | 现状 | 问题 |
|---------|------|------|
| HR注册流程 | ❌ 缺失 | 用户注册后无引导流程 |
| 公司挂靠 | ❌ 缺失 | HR无法选择或创建公司 |
| 角色审批 | ✅ 存在 | 管理员可审批角色，但流程不完整 |
| 公司管理 | ⚠️ 部分 | 有Company模型，但无完整管理流程 |
| HR个人资料 | ⚠️ 部分 | 使用通用ProfilePage，无HR专属信息 |
| 发布职位 | ✅ 存在 | 但无公司挂靠校验 |

### 1.2 核心业务痛点

1. **HR身份认证缺失**：无法验证HR是否真正代表某公司
2. **公司信息不完整**：缺少Logo、图片、详细描述等
3. **信任链条断裂**：顾问无法确认HR的背景和领域
4. **业务流程不闭环**：注册→挂靠→审批→发布 未形成完整链路

## 3. 详细需求规格

### 3.1 HR入驻引导流程（P0 - 核心功能）

#### 3.1.1 注册后引导页面

**功能描述：** HR用户首次登录后，展示入驻引导流程

**页面元素：**
| 元素 | 说明 |
|------|------|
| 欢迎标题 | "欢迎加入JobPortal，开始您的招聘之旅" |
| 步骤指示器 | 1. 选择公司 → 2. 完善资料 → 3. 等待审核 |
| 公司搜索框 | 搜索已存在的公司 |
| 创建公司按钮 | "没有找到您的公司？立即创建" |
| 进度保存 | 每一步自动保存，支持断点续填 |

**交互逻辑：**
```
用户选择HR角色
    │
    ├── 检查是否已完成入驻流程
    │   ├── 是 → 进入工作台
    │   └── 否 → 进入引导流程
    │
    └── 引导流程
        ├── Step 1: 公司挂靠
        │   ├── 搜索公司 → 申请加入 → 等待公司管理员确认
        │   └── 创建公司 → 填写信息 → 提交审核
        │
        ├── Step 2: 个人资料
        │   └── 填写HR专属信息
        │
        └── Step 3: 提交审核
            └── 等待管理员审批
```

#### 3.1.2 公司搜索与选择

**功能描述：** 搜索并选择要挂靠的公司

**搜索字段：**
- 公司名称（模糊匹配）
- 行业领域
- 公司规模

**搜索结果展示：**
| 字段 | 说明 |
|------|------|
| 公司Logo | 80x80px |
| 公司名称 | 主标题 |
| 行业领域 | 标签形式 |
| 公司规模 | 如"100-500人" |
| 认证状态 | 已认证/待认证 |
| 挂靠按钮 | "申请加入" |

**申请加入逻辑：**
1. 用户点击"申请加入"
2. 填写申请说明（职位、部门）
3. 提交申请
4. 通知公司管理员
5. 等待审批

#### 3.1.3 创建新公司

**功能描述：** 创建系统中不存在的公司

**必填信息：**
| 字段 | 类型 | 说明 | 必填 |
|------|------|------|------|
| 公司名称 | 文本 | 公司全称 | ✅ |
| 公司Logo | 图片 | 200x200px，支持裁剪 | ✅ |
| 公司封面 | 图片 | 1200x400px | ⬜ |
| 行业领域 | 选择 | 从预设列表选择 | ✅ |
| 公司规模 | 选择 | 1-50/50-200/200-500/500+ | ✅ |
| 公司简介 | 文本 | 500字以内 | ✅ |
| 公司官网 | URL | 官方网站链接 | ⬜ |
| 公司地址 | 文本 | 详细地址 | ⬜ |
| 联系电话 | 文本 | 公司联系电话 | ⬜ |
| 营业执照号 | 文本 | 用于认证 | ⬜ |
| 营业执照图片 | 图片 | 用于认证审核 | ⬜ |

**图片上传功能：**
- 支持拖拽上传
- 支持裁剪和预览
- 格式限制：JPG/PNG
- 大小限制：Logo 2MB，封面 5MB

### 3.4 审核流程优化（P1 - 重要功能）

#### 3.4.1 HR角色审批

**审批内容：**
| 审批项 | 说明 |
|--------|------|
| 身份验证 | 邮箱后缀是否为公司域名 |
| 公司关联 | 是否成功挂靠公司 |
| 资料完整性 | 必填信息是否完整 |
| 营业执照 | 公司认证材料 |

**审批状态流转：**
```
待审核 → 审核中 → 审核通过 → 已激活
                 ↘ 审核拒绝 → 重新提交
```

#### 3.4.2 公司认证审批

**审批内容：**
| 审批项 | 说明 |
|--------|------|
| 公司名称 | 是否真实存在 |
| 营业执照 | 是否有效 |
| 联系方式 | 是否可联系 |
| 业务范围 | 是否合法合规 |

## 4. 数据模型设计

### 4.1 HR资料模型 (HRProfile)

```typescript
interface HRProfile {
  _id: ObjectId;
  user_id: ObjectId;                    // 关联用户
  company_id: ObjectId;                 // 关联公司
  
  // 基本信息
  position: string;                     // 职位
  department: string;                   // 部门
  avatar_url?: string;                  // 头像
  phone?: string;                       // 联系电话
  work_email?: string;                  // 工作邮箱
  wechat?: string;                      // 微信
  linkedin?: string;                    // LinkedIn
  
  // 专业信息
  recruitment_fields: string[];         // 招聘领域
  years_of_experience: number;          // 从业年限
  summary?: string;                     // 个人简介
  skills: string[];                     // 擅长技能
  success_cases?: string;               // 成功案例
  
  // 统计信息
  stats: {
    jobs_posted: number;                // 发布职位数
    successful_hires: number;           // 成功招聘数
    avg_rating: number;                 // 平均评分
    review_count: number;               // 评价数
  };
  
  // 审核状态
  verification_status: 'pending' | 'approved' | 'rejected';
  verified_at?: Date;
  verified_by?: ObjectId;
  
  created_at: Date;
  updated_at: Date;
}
```

## 8. 风险与注意事项

### 8.1 业务风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 虚假公司注册 | 平台信誉受损 | 营业执照认证 + 人工审核 |
| HR身份造假 | 顾问信任度下降 | 企业邮箱验证 + 电话回访 |
| 公司信息泄露 | 法律风险 | 敏感信息脱敏展示 |

### 8.2 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 图片上传失败 | 用户体验差 | 压缩 + CDN + 重试机制 |
| 搜索性能差 | 响应慢 | Elasticsearch索引 |
| 数据一致性 | 功能异常 | 事务 + 定期校验 |
