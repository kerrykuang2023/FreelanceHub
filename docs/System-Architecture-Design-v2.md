**文档版本:** v2.0  
**创建日期:** 2026-03-28  
**设计理念:** 融合ERP/CRM/SRM最佳实践

---

## 1. 系统定位与核心概念

### 1.1 业务模型对比

| 传统采购 | JobPortal平台 | 说明 |
|----------|---------------|------|
| 采购商 (Buyer) | HR招聘者 | 发布需求、采购服务 |
| 供应商 (Supplier) | 顾问 (Freelancer) | 提供技能服务 |
| 物料/商品 | 技能/服务 | SAP模块技能、实施服务 |
| 采购订单 (PO) | 项目子项 (Assignment) | 每个顾问一个子项 |
| 收货单 (GR) | 工单 (Work Order) | 交付成果确认 |
| 发票 (Invoice) | 付款申请 | 结算请求 |
| 付款 (Payment) | 付款确认 | 资金流转 |

### 1.2 核心业务流程（S2P - Source to Pay）

```
┌─────────────────────────────────────────────────────────────────┐
│              服务采购全链路流程 (Source to Pay)                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  【寻源阶段 Source】                                             │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  HR发布需求 → 顾问响应 → 匹配沟通 → 签约                  │   │
│  │     │            │           │          │               │   │
│  │  项目发布     投递/邀请    面试沟通   合同签订            │   │
│  └─────────────────────────────────────────────────────────┘   │
│                          │                                      │
│                          ▼                                      │
│  【采购阶段 Procure】                                            │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  创建项目子项 → 设置结算条款 → 顾问确认                   │   │
│  │       │              │                │                  │   │
│  │  Assignment    Settlement Rate    Confirm               │   │
│  │  (类似PO抬头)  (单价/付款周期)    (供应商确认)            │   │
│  └─────────────────────────────────────────────────────────┘   │
│                          │                                      │
│                          ▼                                      │
│  【交付阶段 Deliver】                                            │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  顾问工作 → 提交工单 → HR验收 → 确认工时                  │   │
│  │      │          │          │          │                  │   │
│  │  执行任务    Work Order   验收确认    工时确认            │   │
│  │             (类似GR)       (质量检查)                      │   │
│  └─────────────────────────────────────────────────────────┘   │
│                          │                                      │
│                          ▼                                      │
│  【付款阶段 Pay】                                                │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  申请付款 → HR审批 → 付款 → 上传凭证 → 顾问确认          │   │

│                          │                                      │
│                          ▼                                      │

│  ┌─────────────────────────────────────────────────────────┐   │
│  │  HR评价顾问 → 更新能力看板 → 影响匹配权重                 │   │
│  │       │              │                │                  │   │
│  │  绩效评估      技能标签更新      智能推荐优化             │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 核心设计理念

| 理念 | 来源 | 应用场景 |
|------|------|----------|
| **抬头/行项目结构** | SAP ERP | 项目(Project) + 项目子项(Assignment) |
| **三单匹配** | 采购管理 | 工单-验收-付款三单匹配 |
| **供应商门户** | SRM | 顾问工作台 |
| **客户服务** | CRM | 顾问对HR的服务交付 |
| **绩效评估** | SRM | HR对顾问的评价体系 |
| **审批工作流** | ERP | 工单审批、付款审批 |

### 3.2 状态机设计

#### 3.2.1 项目子项状态流转

```
┌─────────────────────────────────────────────────────────────────┐
│              ProjectAssignment 状态流转                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  [创建] ──→ pending ──→ confirmed ──→ active ──→ completed      │
│              │              │           │            │          │
│              │              │           │            │          │
│              │              │           │            │          │
│              ▼              ▼           ▼            ▼          │
│           [取消]        [终止]     [终止]       [归档]          │
│                                      │                          │
│                                      ▼                          │
│                                  terminated                     │
│                                                                 │
│  状态说明:                                                       │
│  • pending: HR创建，等待顾问确认                                 │
│  • confirmed: 顾问已确认，等待项目开始                           │
│  • active: 项目进行中                                           │
│  • completed: 项目已完成                                         │
│  • terminated: 项目已终止                                        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 5. 关键业务规则

### 5.1 结算单价规则

```
┌─────────────────────────────────────────────────────────────────┐
│                    结算单价规则                                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  【规则1: 单价设置】                                             │
│  • HR在创建ProjectAssignment时设置单价                          │
│  • 同一项目不同顾问可以有不同单价                                │
│  • 单价对其他顾问不可见                                          │
│                                                                 │
│  【规则2: 单价锁定】                                             │
│  • 顾问确认后，单价锁定                                          │
│  • 工单创建时，从Assignment读取单价快照                          │
│  • 工单中的单价不可修改                                          │
│                                                                 │
│  【规则3: 单价变更】                                             │
│  • 如需变更单价，HR需创建新的Assignment                          │
│  • 或终止当前Assignment，重新创建                                │
│                                                                 │
│  【规则4: 自动计算】                                             │
│  • 工单金额 = 工时/天数 × 单价                                   │
│  • 系统自动计算，顾问和HR均可预览                                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 5.2 三单匹配规则

```
┌─────────────────────────────────────────────────────────────────┐
│                    三单匹配规则                                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  【采购订单】ProjectAssignment                                   │
│  • 约定结算单价                                                  │
│  • 约定付款周期                                                  │
│  • 约定里程碑                                                    │
│                                                                 │
│  【收货单】WorkOrder                                             │
│  • 记录实际交付                                                  │
│  • HR验收确认                                                    │
│  • 关联到Assignment                                              │
│                                                                 │
│  【发票】PaymentRequest                                          │
│  • 基于已审批的WorkOrder                                         │
│  • 金额不能超过Assignment约定                                    │
│  • 三单匹配后才能付款                                            │
│                                                                 │
│  【匹配规则】                                                     │
│  Assignment.work_summary.total_payment                          │
│      = SUM(WorkOrder.payment.amount)                            │
│      = SUM(PaymentRequest.amount)                               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
