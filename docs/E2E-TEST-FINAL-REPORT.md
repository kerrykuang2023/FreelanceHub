## 3. 测试设计说明

### 3.1 串行依赖模式

测试采用 **串行模式** (`mode: 'serial'`)，确保：

1. **依赖关系正确** - 前一步骤成功后才执行下一步骤
2. **数据流转验证** - 验证数据在不同角色之间的流转
3. **业务逻辑完整** - 覆盖从项目创建到付款确认的完整流程

### 3.2 业务流程依赖链

```
HR登录 → HR创建项目 → 顾问登录 → 顾问浏览项目 → 顾问申请项目
    ↓
HR审批申请 → 顾问填报工时 → HR确认工时 → 顾问创建发票
    ↓
HR审核发票 → HR确认付款 → 顾问确认收款
```
