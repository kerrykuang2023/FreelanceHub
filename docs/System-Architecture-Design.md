### 1.2 用户角色与场景

| 角色 | 定位 | 核心场景 |
|------|------|----------|
| **顾问 (Freelancer)** | 供应商 | 展示技能 → 接项目 → 做项目 → 收款 |
| **HR招聘者** | 采购商 | 发布项目 → 找人 → 管理项目 → 付款 |
| **企业管理员** | 企业管理 | 管理公司 → 管理HR → 审批合同 |
| **系统管理员** | 平台管理 | 用户管理 → 数据配置 → 系统运维 |

## 2. 工作广场 (Work Plaza)

### 2.1 概念定义

工作广场是供需对接平台，类似于 SAP Ariba Network：
- **顾问** = 供应商，售卖技能和服务
- **HR** = 采购商，发布项目需求
- 双方在这里进行**匹配、沟通、签约**

### 2.2 功能模块

```
工作广场 (Work Plaza):
│
├── 首页 (Home)
│   ├── 平台介绍
│   ├── 热门项目推荐
│   ├── 优秀顾问展示
│   └── 统计数据
│
├── 项目市场 (Project Market)
│   ├── 项目列表（顾问视角）
│   ├── 项目详情
│   ├── 投递申请
│   └── 收藏项目
│
├── 人才市场 (Talent Market)
│   ├── 顾问列表（HR视角）
│   ├── 顾问详情/能力看板
│   ├── 状态筛选（可接单/项目中/即将空闲）
│   └── 邀请投递
│
├── 消息中心 (Messages)
│   ├── 即时通讯
│   ├── 系统通知
│   └── 面试邀请
│
└── 合同中心 (Contracts)
    ├── 合同模板
    ├── 合同签署
    └── 合同归档
```

### 2.3 供需匹配流程

```
┌─────────────────────────────────────────────────────────────────┐
│                    供需匹配流程                                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  【顾问主动】                                                    │
│  浏览项目 → 感兴趣 → 投递申请 → HR查看 → 沟通 → 签约             │
│                                                                 │
│  【HR主动】                                                      │
│  浏览人才 → 筛选状态 → 查看能力 → 发送邀请 → 沟通 → 签约         │
│                                                                 │
│  【系统推荐】                                                    │
│  技能匹配 → 推送项目/人才 → 查看详情 → 沟通 → 签约               │
│                                                                 │
│  【签约成功后】                                                  │
│  创建ProjectAssignment → 进入工作台 → 开始协作                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 7. 实施路线图

### 7.1 第一阶段：工作广场基础

| 任务 | 描述 | 优先级 |
|------|------|--------|
| 项目市场页面 | 项目列表、详情、搜索 | P0 |
| 人才市场页面 | 顾问列表、详情、筛选 | P0 |
| 申请/邀请流程 | 投递申请、邀请投递 | P0 |
| 消息中心 | 基础消息功能 | P1 |

### 7.2 第二阶段：工作台核心

| 任务 | 描述 | 优先级 |
|------|------|--------|
| ProjectAssignment API | 项目子项CRUD | P0 |
| WorkOrder API | 工单CRUD和状态流转 | P0 |
| HR项目详情页 | 显示项目子项列表 | P0 |
| 顾问项目详情页 | 显示自己的子项信息 | P0 |
| 工单审批流程 | HR审批、付款 | P0 |
| 顾问状态管理 | 可接单/项目中/即将空闲 | P1 |

### 7.3 第三阶段：系统管理

| 任务 | 描述 | 优先级 |
|------|------|--------|
| 用户管理优化 | 用户审核、角色审批 | P1 |
| 基础数据管理 | 技能分类、行业分类 | P1 |
| 数据统计 | 平台数据统计 | P2 |
| 日志审计 | 操作日志、审计 | P2 |

### 8.1 前端路由结构

```typescript
// 路由结构
const routes = {
  // 工作广场 (公开)
  plaza: {
    path: '/plaza',
    children: [
      { path: '/', element: PlazaHome },
      { path: '/projects', element: ProjectMarket },

  },
  
  // 顾问工作台 (需登录)

    path: '/freelancer',
```

### 8.2 API 结构

```typescript
// API 路由结构
const apiRoutes = {
  // 工作广场 API
  '/api/v1/plaza': {
    GET  /projects          // 项目列表
    GET  /projects/:id      // 项目详情
    GET  /talents           // 人才列表
    GET  /talents/:id       // 人才详情
    POST /applications      // 投递申请
    POST /invitations       // 邀请投递
  },
  
  // 项目子项 API
  '/api/v1/assignments': {
    GET    /                // 获取我的项目子项
    GET    /:id             // 获取项目子项详情
    POST   /                // HR创建项目子项
    PUT    /:id             // 更新项目子项
    PUT    /:id/confirm     // 顾问确认
    PUT    /:id/start       // 开始项目
    PUT    /:id/complete    // 完成项目
  },
  
  // 工单 API
  '/api/v1/work-orders': {
    GET    /                // 获取工单列表
    GET    /:id             // 获取工单详情
    POST   /                // 创建工单
    PUT    /:id             // 更新工单
    PUT    /:id/submit      // 提交审批
    PUT    /:id/approve     // HR审批通过
    PUT    /:id/reject      // HR审批驳回
    PUT    /:id/request-payment  // 申请付款
    PUT    /:id/confirm-payment  // 确认付款
    POST   /:id/dispute     // 提交异议
    PUT    /:id/resolve-dispute  // 解决异议
  },
  
  // 顾问状态 API
  '/api/v1/freelancer/status': {
    GET    /                // 获取状态
    PUT    /                // 更新状态
  },
  
  // 系统管理 API
  '/api/v1/admin': {
    // 用户管理
    GET    /users           // 用户列表
    PUT    /users/:id/approve  // 审批用户
    PUT    /users/:id/role    // 分配角色
    
    // 企业管理
    GET    /companies       // 企业列表
    PUT    /companies/:id/approve  // 审批企业
    
    // 基础数据
    GET    /master-data     // 获取基础数据
    PUT    /master-data     // 更新基础数据
  },
};
```
