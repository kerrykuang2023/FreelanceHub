## 3. 运行测试

### 3.1 环境准备

```bash
# 安装依赖
npm install

# 创建测试截图目录
mkdir -p test-results/screenshots

# 启动服务器
cd JobPortal/server && npm run dev
```

### 3.2 运行全部测试

```bash
# 运行所有测试
npx playwright test e2e-comprehensive-test.spec.ts

# 可视化运行
npx playwright test e2e-comprehensive-test.spec.ts --headed

# 生成报告
npx playwright test e2e-comprehensive-test.spec.ts --reporter=html
```

### 3.3 运行特定模块

```bash
# 只运行系统管理测试
npx playwright test e2e-comprehensive-test.spec.ts -g "系统管理"

# 只运行HR测试
npx playwright test e2e-comprehensive-test.spec.ts -g "HR角色"

# 只运行UI测试
npx playwright test e2e-comprehensive-test.spec.ts -g "UI/UX"
```

## 6. 手动测试指南

### 6.1 完整业务流程手动测试

#### 流程1: HR发布项目 → 顾问申请 → HR审核

```
1. HR登录 (hr@test.com / Test1234!)
2. 访问 /post-job
3. 填写项目信息并发布
4. 退出登录

5. 顾问登录 (freelancer@test.com / Test1234!)
6. 访问 /jobs
7. 点击项目查看详情
8. 点击"申请"按钮
9. 退出登录

10. HR登录
11. 访问 /applications
12. 查看申请并批准/拒绝
```

#### 流程2: 顾问填报工时 → HR审核 → 创建发票

```
1. 顾问登录
2. 访问 /work-logs/new
3. 选择项目、填写工时
4. 提交工时
5. 退出登录

6. HR登录
7. 访问 /work-logs
8. 审核工时（确认/驳回）
9. 退出登录

10. 顾问登录
11. 访问 /invoices/new
12. 创建发票
```

#### 流程3: 发票审核 → 付款确认

```
1. HR登录
2. 访问 /invoices
3. 审核发票（通过/驳回）
4. 访问 /payments
5. 确认付款
```

## 7. 注意事项

1. **测试前确保数据库已清理**
   ```bash
   npx ts-node src/scripts/clean-test-data.ts
   npx ts-node src/scripts/seed-test-users.ts
   ```

2. **确保服务器已启动**
   - 后端服务: http://localhost:5000
   - 前端服务: http://localhost:5173

3. **测试失败时查看截图**
   - 截图保存在 `test-results/screenshots/`

4. **调试模式**
   ```bash
   npx playwright test e2e-comprehensive-test.spec.ts --debug
   ```
