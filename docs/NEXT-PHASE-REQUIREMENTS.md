## 2. P0需求（必须修复）

### REQ-001: 修复项目发布后不显示在列表的问题

**问题描述:**
HR成功发布项目后，顾问在项目列表页面看不到新发布的项目。

**复现步骤:**
1. HR登录系统
2. 访问发布项目页面
3. 填写项目信息并提交
4. 项目创建成功
5. 顾问登录系统
6. 访问项目列表页面
7. 列表为空，找不到刚发布的项目

**预期行为:**
项目发布成功后，应立即在项目列表中显示，顾问可以浏览和申请。

**可能原因分析:**
1. 项目创建后状态默认为draft，需要额外操作才能发布
2. 项目列表API有筛选条件，过滤掉了新创建的项目
3. 数据同步延迟

**修复建议:**
1. 检查项目创建API，确保status字段设置正确
2. 检查项目列表API的筛选条件
3. 确保创建后数据立即可查询

**涉及文件:**
- `server/src/controllers/jobs.controller.ts`
- `server/src/models/job.model.ts`
- `client/src/pages/JobsListPage/JobsListPage.tsx`

**预估工时:** 2小时

## 4. P2需求（体验优化）

### REQ-011: 为关键元素添加data-testid属性

**问题描述:**
大部分页面元素缺少data-testid属性，导致自动化测试难以定位元素。

**修复建议:**
为以下元素添加data-testid属性：
- 所有表单提交按钮
- 所有输入框
- 所有选择器
- 所有操作按钮（编辑、删除、确认等）
- 列表项和卡片

**涉及文件:**
- 所有前端页面组件
