# 全面端到端测试计划

**文档版本:** v1.0  
**创建日期:** 2026-03-28  
**测试原则:** 业务逻辑依赖优先 + 多场景数据覆盖 + 前后端一致性验证

---

## 1. 测试设计原则

### 1.1 核心设计理念

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           测试设计核心原则                                    │
└─────────────────────────────────────────────────────────────────────────────┘

1. 业务依赖优先
   ├── 系统配置必须先于业务操作
   ├── 公司注册必须先于HR注册
   ├── HR发布项目必须先于顾问申请
   ├── 申请批准必须先于工时填报
   └── 工时确认必须先于发票创建

2. 多场景数据覆盖
   ├── 正向流程：标准成功路径
   ├── 反向流程：异常状态拒绝
   ├── 边界条件：极限值测试
   └── 状态流转：多状态转换

3. 前后端一致性验证
   ├── 前端显示数据 = 后端API返回数据
   ├── 前端状态变化 = 后端数据库状态变化
   ├── 操作结果 = 预期结果
   └── 关联数据同步更新

4. 跨角色协作验证
   ├── HR操作 → 顾问可见
   ├── 顾问操作 → HR可见
   ├── 管理员操作 → 全局生效
   └── 状态联动 → 相关角色感知
```

### 1.2 测试数据设计原则

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           测试数据设计原则                                    │
└─────────────────────────────────────────────────────────────────────────────┘

1. 多公司多项目
   ├── 公司A: 已认证，可发布项目
   ├── 公司B: 待认证，不可发布项目
   └── 公司C: 已禁用，不可操作

2. 多顾问多状态
   ├── 顾问A: 已分配项目，可填报工时
   ├── 顾问B: 未分配项目，只能浏览
   └── 顾问C: 已禁用，不可登录

3. 多项目多状态
   ├── 项目A: 草稿状态，可编辑
   ├── 项目B: 已发布，可申请
   ├── 项目C: 进行中，可填报工时
   ├── 项目D: 已关闭，不可操作
   └── 项目E: 已到期，不可申请

4. 多申请多状态
   ├── 申请A: 待审核，可批准/拒绝
   ├── 申请B: 已批准，项目已分配
   ├── 申请C: 已拒绝，可重新申请
   └── 申请D: 已撤回，可重新申请

5. 多工时多状态
   ├── 工时A: 草稿，可编辑/删除
   ├── 工时B: 已提交，可确认/驳回
   ├── 工时C: 已确认，可开票
   ├── 工时D: 已驳回，可修改重提
   └── 工时E: 已开票，不可修改

6. 多发票多状态
   ├── 发票A: 草稿，可编辑
   ├── 发票B: 已提交，可审批/驳回
   ├── 发票C: 已审批，可付款
   ├── 发票D: 已付款，可确认收款
   └── 发票E: 已收款，流程结束
```

### 6.1 前后端数据一致性验证

```typescript
interface VerificationResult {
  frontend: {
    status: string;
    count: number;

async function verifyDataConsistency(
  page: Page,
  request: APIRequestContext,
  options: {
    entityType: 'project' | 'application' | 'worklog' | 'invoice';
    entityId?: string;
    expectedStatus?: string;
  }
): Promise<VerificationResult> {
  const differences: string[] = [];
  
  // 获取前端数据
  const frontendData = await getFrontendData(page, options);
  
  // 获取后端数据
  const backendData = await getBackendData(request, options);
  
  // 比较状态
  if (frontendData.status !== backendData.status) {
    differences.push(`状态不一致: 前端=${frontendData.status}, 后端=${backendData.status}`);
  }
  
  // 比较数量
  if (frontendData.count !== backendData.count) {
    differences.push(`数量不一致: 前端=${frontendData.count}, 后端=${backendData.count}`);
  }
  
  return {
    frontend: frontendData,
    backend: backendData,
    isConsistent: differences.length === 0,
    differences,
  };
}
```

```typescript
async function verifyStateTransition(
  page: Page,
  request: APIRequestContext,
  options: {
    entityType: string;
    entityId: string;
    fromStatus: string;
    toStatus: string;
    operation: () => Promise<void>;
  }
): Promise<{
  success: boolean;
  beforeStatus: string;
  afterStatus: string;
  frontendStatus: string;
  backendStatus: string;
}> {

  const beforeStatus = await getEntityStatus(request, options.entityId);
  
  // 执行操作
  await options.operation();
  
  // 等待状态更新
  await page.waitForTimeout(2000);
  
  // 获取操作后状态
  const afterStatus = await getEntityStatus(request, options.entityId);
  const frontendStatus = await getFrontendStatus(page, options.entityId);
  
  // 验证状态流转
  const success = 
    beforeStatus === options.fromStatus &&
    afterStatus === options.toStatus &&
    frontendStatus === options.toStatus;
  
  return {
    success,
    beforeStatus,
    afterStatus,
    frontendStatus,
    backendStatus: afterStatus,
  };
}
```
