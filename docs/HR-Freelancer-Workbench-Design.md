# HR与顾问工作台协同设计方案

**文档版本:** v3.0  
**创建日期:** 2026-03-28  
**设计原则:** 数据结构一致、权限分离、流程协同

---

## 1. 数据模型架构

### 1.1 三层结构设计（类似SAP抬头/行项目）

```
┌─────────────────────────────────────────────────────────────────┐
│                    项目订单结构                                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  【Project 项目】 - 抬头订单                                      │
│  ├── 公开信息（HR + 顾问可见）                                    │
│  │   ├── 项目名称、描述                                          │
│  │   ├── 项目周期、地点                                          │
│  │   ├── 技能要求                                                │
│  │   └── 工作形式（远程/现场）                                    │
│  │                                                              │
│  └── 私有信息（仅HR可见）                                         │
│      ├── 预算范围                                                │
│      └── 内部备注                                                │
│                                                                 │
│  【ProjectAssignment 项目子项】 - 行项目                          │
│  ├── 每个顾问一个子项                                            │
│  ├── 结算单价（顾问A: ¥1500/天，顾问B: ¥1300/天）                 │
│  ├── 合同信息                                                    │
│  ├── 里程碑列表                                                  │
│  └── 工作统计                                                    │
│                                                                 │
│  【WorkOrder 工单】 - 工时/里程碑交付                             │
│  ├── 关联到ProjectAssignment                                    │
│  ├── 从Assignment读取结算单价（不可修改）                         │
│  ├── 工作成果                                                    │
│  └── 付款状态                                                    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 数据模型关系

```typescript
Project (项目)
  │
  ├── ProjectAssignment (项目子项) ──── 顾问A
  │     ├── settlement: { rate_amount: 1500, rate_type: 'daily' }
  │     ├── contract: { ... }
  │     ├── milestones: [ ... ]
  │     │
  │     └── WorkOrder (工单1)
  │     └── WorkOrder (工单2)
  │
  ├── ProjectAssignment (项目子项) ──── 顾问B
  │     ├── settlement: { rate_amount: 1300, rate_type: 'daily' }
  │     │
  │     └── WorkOrder (工单1)
  │
  └── ProjectAssignment (项目子项) ──── 顾问C
        └── ...
```

## 4. 协同流程

### 4.1 完整业务流程

```
┌─────────────────────────────────────────────────────────────────┐
│                    HR与顾问协同流程                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  【阶段1：项目创建与顾问分配】                                     │
│                                                                 │
│  HR发布项目 ──→ HR筛选顾问 ──→ HR创建项目子项                     │
│                      │              │                           │
│                      │              ├── 设置结算单价            │
│                      │              ├── 设置里程碑              │
│                      │              └── 发送邀请                │
│                      │                                          │
│                      └──→ 顾问收到邀请 ──→ 确认/拒绝             │
│                                                                 │
│  【阶段2：合同签订】                                              │
│                                                                 │
│  顾问确认 ──→ HR上传合同 ──→ 顾问签署 ──→ 项目开始               │
│                                                                 │
│  【阶段3：工单-付款循环】                                         │
│                                                                 │
│  顾问提交工单 ──→ HR审批 ──→ 通过/驳回                           │
│       │                    │                                    │
│       │                    ├── 通过 ──→ 顾问申请付款            │
│       │                    │              │                     │
│       │                    │              └──→ HR付款并上传凭证  │
│       │                    │                        │           │
│       │                    │                        └──→ 顾问确认│
│       │                    │                                    │
│       │                    └── 驳回 ──→ 顾问修改后重新提交       │
│       │                                                         │
│       └── 异议 ──→ 提交申诉 ──→ 管理员处理 ──→ 解决/关闭        │
│                                                                 │
│  【阶段4：项目完成】                                              │
│                                                                 │
│  所有里程碑完成 ──→ HR确认项目结束 ──→ 自动更新顾问简历           │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 权限控制

| 数据字段 | HR可见 | 顾问可见 | 说明 |
|----------|--------|----------|------|
| 项目基本信息 | ✅ | ✅ | 双方一致 |
| 项目预算 | ✅ | ❌ | 仅HR可见 |
| 内部备注 | ✅ | ❌ | 仅HR可见 |
| 自己的结算单价 | ✅ | ✅ | 只能看自己的 |
| 他人的结算单价 | ✅ | ❌ | 不可见 |
| 自己的工单 | ✅ | ✅ | 只能看自己的 |
| 他人的工单 | ✅ | ❌ | 不可见 |
