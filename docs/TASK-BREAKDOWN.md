## 任务执行说明

### 执行规范

1. **每个任务必须按照以下流程执行：**
   - 需求理解 → 设计方案 → 编码实现 → 单元测试 → E2E测试 → UI测试 → 文档更新
   - 每个阶段完成后必须验证通过才能进入下一阶段

2. **测试要求：**
   - 每个功能必须有对应的单元测试
   - 核心流程必须有E2E测试
   - 所有UI组件必须有UI测试
   - 测试覆盖率：单元测试 ≥ 80%，E2E测试 ≥ 90%核心流程

3. **Issue处理：**
   - 发现问题立即创建Issue记录
   - 更新任务清单，添加修复任务
   - 修复后必须通过所有测试才能关闭Issue

4. **文档更新：**
   - 每个任务完成后更新相关文档
   - API变更必须更新API文档
   - 数据模型变更必须更新数据库设计文档

### TASK-001: 智能匹配推荐算法 - 技能匹配

**优先级:** P0  
**预估工时:** 8小时  
**依赖:** 无  

#### 需求描述 (EARS格式)

```
WHEN 用户浏览项目列表时, THE SYSTEM SHALL 根据用户技能自动计算匹配度并排序
WHEN 用户查看项目详情时, THE SYSTEM SHALL 显示该用户与项目的技能匹配度
WHERE 用户设置了主技能, THE SYSTEM SHALL 优先展示主技能匹配的项目
```

#### 详细任务

| 子任务 | 描述 | 验收标准 |
|--------|------|----------|
| 001-1 | 创建技能匹配服务 `skill-match.service.ts` | 服务文件创建成功，包含匹配算法 |
| 001-2 | 实现技能匹配度计算函数 | 输入用户技能列表和项目技能要求，返回匹配度分数(0-100) |
| 001-3 | 实现技能匹配算法：完全匹配得100分 | 用户技能完全覆盖项目要求技能时返回100 |
| 001-4 | 实现技能匹配算法：部分匹配按比例得分 | 匹配技能数/要求技能数 * 100 |
| 001-5 | 实现技能匹配算法：不匹配得0分 | 用户技能与项目要求无交集时返回0 |
| 001-6 | 实现主技能权重加成 | 主技能匹配时额外加20分(最高100分) |
| 001-7 | 创建匹配度API接口 `GET /api/v1/match/score` | 返回用户与指定项目的匹配度 |
| 001-8 | 在项目列表API中集成匹配度排序 | 项目列表按匹配度降序排列 |
| 001-9 | 编写单元测试 | 覆盖率 ≥ 90% |
| 001-10 | 编写E2E测试 | 验证匹配排序功能 |
| 001-11 | 更新API文档 | 文档包含匹配算法说明 |

#### 技术实现要点

```typescript
// 匹配度计算函数签名
interface SkillMatchInput {
  userSkills: string[];        // 用户技能ID列表
  primarySkills: string[];     // 用户主技能ID列表
  requiredSkills: string[];    // 项目要求技能ID列表
}

interface SkillMatchResult {
  score: number;               // 匹配度分数 0-100
  matchedSkills: string[];     // 匹配的技能列表
  unmatchedSkills: string[];   // 未匹配的技能列表
  primaryMatched: boolean;     // 主技能是否匹配
}

function calculateSkillMatch(input: SkillMatchInput): SkillMatchResult;
```

#### 测试用例

```typescript
describe('Skill Match Service', () => {
  test('should return 100 when all skills match', () => {
    const result = calculateSkillMatch({
      userSkills: ['skill1', 'skill2', 'skill3'],
      primarySkills: ['skill1'],
      requiredSkills: ['skill1', 'skill2'],
    });
    expect(result.score).toBe(100);
  });

  test('should return 50 when half skills match', () => {
    const result = calculateSkillMatch({
      userSkills: ['skill1', 'skill2'],
      primarySkills: [],
      requiredSkills: ['skill1', 'skill2', 'skill3', 'skill4'],
    });
    expect(result.score).toBe(50);
  });

  test('should add bonus for primary skill match', () => {
    const result = calculateSkillMatch({
      userSkills: ['skill1', 'skill2'],
      primarySkills: ['skill1'],
      requiredSkills: ['skill1'],
    });
    expect(result.score).toBe(100); // 100 + 20 = 100 (max)
  });
});
```

#### 技术实现要点

```typescript
interface MatchScore {
  skillScore: number;      // 技能匹配度 0-100
  locationScore: number;   // 地域匹配度 0-100
  rateScore: number;       // 费率匹配度 0-100
  availabilityScore: number; // 可用性匹配度 0-100
  totalScore: number;      // 总分 0-100
  breakdown: {
    skill: number;         // 技能权重分 = skillScore * 0.4
    location: number;      // 地域权重分 = locationScore * 0.2
    rate: number;          // 费率权重分 = rateScore * 0.2
    availability: number;  // 可用性权重分 = availabilityScore * 0.2
  };
}

// 总分计算公式
totalScore = skillScore * 0.4 + locationScore * 0.2 + rateScore * 0.2 + availabilityScore * 0.2;
```
