## 三、测试结果验证 (Test Validation)

### 3.1 结果分析

**通过标准:**

- [ ] 所有 P0 功能测试通过 (100%)
- [ ] P1 功能测试通过率 >= 80%
- [ ] 无阻塞性问题
- [ ] 截图证据完整

**失败处理:**

- [ ] 查看错误日志
  - 命令：`cat test-results/[test-name]/error-context.md`
  
- [ ] 分析失败原因
  - [ ] 环境问题
  - [ ] 测试脚本问题
  - [ ] 功能实现问题
  
- [ ] 记录问题到问题清单

### 3.2 问题记录

**问题记录表:**

| 序号 | 功能 ID | 问题描述 | 严重级别 | 复现步骤 | 预期结果 | 实际结果 |
|------|---------|----------|----------|----------|----------|----------|
| 1 | | | P0/P1/P2 | | | |
| 2 | | | P0/P1/P2 | | | |
| 3 | | | P0/P1/P2 | | | |

**严重级别定义:**

- **P0 (阻塞):** 核心功能无法使用，必须立即修复
- **P1 (严重):** 主要功能受损，当日内修复
- **P2 (一般):** 次要功能问题，2 日内修复
- **P3 (轻微):** UI/体验问题，迭代中修复
