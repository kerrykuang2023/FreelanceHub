### 2.5 补充：项目状态流转 (PRD 4.2.2 补充)

```markdown
### 4.2.2 项目状态流转（补充）

项目状态增加以下状态：

| 状态 | 描述 | 可转换状态 |
|------|------|------------|
| 草稿 | 项目创建中，未发布 | 发布 |
| 已发布 | 开放申请中 | 进行中、已关闭、已暂停 |
| 进行中 | 已有顾问参与 | 已完成、已暂停、已关闭 |
| 已暂停 | 临时暂停，可恢复 | 进行中、已关闭 |
| 已完成 | 项目正常结束 | - |
| 已关闭 | 提前终止或取消 | - |

状态流转规则：
1. 草稿 → 已发布：需要完善项目基本信息
2. 已发布 → 进行中：至少有一名顾问被录用
3. 进行中 → 已暂停：HR可主动暂停，需填写原因
4. 已暂停 → 进行中：HR可恢复项目
5. 任何状态 → 已关闭：需要确认操作
```
