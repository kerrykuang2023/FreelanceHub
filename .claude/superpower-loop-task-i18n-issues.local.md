## 根本原因分析

### 1. 前端代码未正确编译

可能原因：
- Vite热重载未正确更新
- TypeScript编译错误导致组件未加载

### 2. 测试选择器与实际组件不匹配

测试用例中的选择器：
```typescript
await page.locator('[data-testid="email-input"]')
```

实际组件中的选择器：
```tsx
<input data-testid="email-input" ... />
```

### 3. 服务启动顺序问题

测试可能在服务完全启动前开始执行
