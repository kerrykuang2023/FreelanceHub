# 任务执行提示词模板

## 使用说明

当会话意外重启或新建任务时，使用以下提示词快速恢复工作状态。

---

## 快速恢复提示词

```
请执行以下任务恢复流程：

### 第一步：读取关键文档
1. 读取 `.trae/rules/feature-development-workflow.md` 了解工作规范
2. 读取 `docs/PRD-Feature-Checklist.md` 了解当前完成情况
3. 读取 `docs/PRD-Freelancer-Platform.md` 了解PRD需求

### 第二步：分析当前状态
根据检查清单，回答以下问题：
- P0功能完成率是多少？还有哪些未完成？
- P1功能完成率是多少？还有哪些未完成？
- 当前最紧急的任务是什么？

### 第三步：生成任务清单
将未完成的功能ID按优先级排序，使用TodoWrite工具创建任务清单。

### 第四步：执行任务
按照工作规范执行任务，完成后进行验证和汇报。
```

## 模板使用示例

### 示例1：开始新的一天工作

```
请开始今日工作：

1. 读取 `docs/PRD-Feature-Checklist.md` 了解当前进度
2. 确认今日要完成的P0功能
3. 使用TodoWrite创建今日任务清单
4. 开始执行第一个任务

完成后请汇报今日工作计划。
```

### 示例2：完成一个模块后继续

```
我刚完成了 [模块名称] 模块的开发，请：

1. 更新 `docs/PRD-Feature-Checklist.md`
2. 汇报当前整体进度
3. 确定下一个要开发的模块
4. 开始执行

请按照工作规范继续。
```

## 关键提醒

使用以上提示词时，请注意：

1. **始终先读取关键文档**：工作规范、检查清单、PRD
2. **使用TodoWrite跟踪任务**：确保任务可追溯
3. **完成后更新检查清单**：保持状态同步
4. **生成完成报告**：记录工作成果
5. **总结经验教训**：持续改进流程
