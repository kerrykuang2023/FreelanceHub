## 7. 常用命令速查

### 7.1 开发命令

```bash
# 启动开发服务器
npm run dev

# 构建项目
npm run build

# 类型检查
npx tsc --noEmit

# 代码检查
npx eslint src/ --ext .ts,.tsx
```

### 7.2 测试命令

```bash
# 运行所有测试
npx playwright test

# 运行特定测试
npx playwright test tests/freelancer/auth.spec.ts

# 可视化运行
npx playwright test --headed

# 查看报告
npx playwright show-report
```

### 7.3 Git命令

```bash
# 查看状态
git status

# 提交代码
git add . && git commit -m "message"

# 查看日志
git log --oneline -10

# 推送代码
git push
```
